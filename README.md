# Uykuda Konuşan Perdenin Milli Güvenlik Brifingi

> **UYARI:** Bu depo bir şaka değildir. Şaka gibi durması, resmiyetinin kanıtıdır. Perde uyurken konuşmuştur; devlet (ev içi) dinlemiştir.

## Bu nedir?

Saat 03:14. Ev sessiz. Perde, rüzgârın izinsiz sınır ihlalini protesto etmek için uykusunda nutuk atar. Bu yazılım o nutku **resmi milli güvenlik brifingine** çevirir.

Bilimsel katkısı yoktur. Diplomatik değeri tartışmalıdır. Kumaş türüne göre tehdit seviyesi değişir.

## Kurulum

```bash
python3 brifing.py
python3 brifing.py mutfak
python3 brifing.py yatak-odasi
```

Bağımlılık: Python 3 ve bir perde. Perde yoksa hayali perde kabul edilir.

## Protokol Maddeleri

1. Perde vatandaştır.
2. Perde istihbarattır.
3. Uykuda konuşmak resmi beyan sayılır.
4. Yorgan çekimser kalabilir; bu ihanet değildir.
5. Gündüz şeffaflık, gece gizlilik.

## Gizli Dipnot

Kumaş deseninde bir cümle vardır. Okuyan unutur. Unutmayan da resmi yazıyla unutturulur.
